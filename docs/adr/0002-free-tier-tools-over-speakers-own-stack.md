# Workshop uses bolt.new and GitHub Copilot Free, not the speaker's own Claude Code

- Status: Accepted
- Date: 2026-08-19

The speaker's daily-driver tool for agentic engineering is Claude Code (paid). The Afternoon Workshop instead has students vibe-code in bolt.new (fallback: Google AI Studio Build) for Act 1, and use VS Code with GitHub Copilot Free's agent mode for Act 3, on their own laptops (BYOD).

Considered alternative: teach with Claude Code throughout, matching the morning lecture's real-world examples, and ask the school or students to cover a short paid trial.

Decided against it because Silliman's administration confirmed no institutional bulk license is available for the event ("licenses are personal in nature"), roughly 30-40 students will actually be hands-on, and the great majority have no credit card or paid subscription. As of August 2026, GitHub Copilot Pro's student verification path is also closed (GitHub paused new Student Developer Pack signups in April 2026), removing what would otherwise have been the natural free path to a Claude-model-backed agentic tool. Copilot Free's agent mode is confirmed genuinely agentic (multi-step, tool use, self-correcting) and free with zero signup friction, which was the deciding constraint over matching the speaker's own stack. The mismatch between the morning's Claude Code examples and the afternoon's different tools is called out directly in the workshop deck rather than left implicit, since a reasonable attendee would otherwise wonder why the tools changed.
