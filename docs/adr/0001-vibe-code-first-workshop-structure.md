# Afternoon Workshop opens with vibe-coding, not agentic engineering

- Status: Accepted
- Date: 2026-08-19

The Afternoon Workshop spends its first act (~40 of 120 minutes) having students one-shot a small app on a free browser tool, before any Spec, ADR, or Critical Review is introduced — the exact undisciplined process the talk otherwise argues against.

Considered alternative: open directly with the disciplined Spec-first workflow, saving vibe-coding for a contrasting aside or skipping it.

Decided to lead with vibe-coding because the Critical Review in Act 2 needs a concrete, student-owned artifact with real flaws to critique — a hypothetical or the speaker's own polished example doesn't land the same way for a mixed-literacy room seeing agentic tooling for the first time. Students feel the speed and the gaps themselves before being told agentic engineering fixes them, which is a stronger argument than being told upfront. The same requirement (CCS Event Board) is rebuilt in Act 3 from a written Spec, so the room sees one artifact under two processes rather than two disconnected demos.
