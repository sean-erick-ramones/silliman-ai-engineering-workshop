Workshop prep memo · agentic engineering, Silliman University

The No-Card Stack

Which free, genuinely agentic coding tool survives a 45‑minute classroom session with zero payment walls — checked live against August 2026 sources, not stale training data.

Prepared 17 Aug 2026  ·  audience: CS students with no cards, no subscriptions, a university email, and a plausible GitHub account

Two assumptions from six months ago no longer hold GitHub froze all new Copilot Pro, Pro+, and Student Developer Pack signups on 20 Apr 2026, with no reopening date announced — the old "verify your student status, get Copilot Pro" plan is dead for now.[1,8] And Google sunset Gemini CLI for personal/free Google accounts on 18 Jun 2026, folding individual users into a new "Antigravity CLI" whose free quota multiple users report exhausting in minutes.[11,12,13,14] Both change the shape of this recommendation.

Best option

Works today, for every student, with nothing to verify and nothing to wait on.

Recommended

GitHub Copilot Free + VS Code Agent Mode (+ Copilot CLI)

No card, no student verification, no waiting period — just a GitHub account. Copilot's Free tier (confirmed live on its plans page) gives 2,000 completions/month, agent mode, and the Copilot CLI, plus chat access to Claude Haiku 4.5 and GPT‑5 mini.[7] Agent mode does genuine multi-step work — it plans, edits files across a repo, runs commands, and revises when something fails — and the CLI gives a terminal-first flavor close to Claude Code's own workflow, which makes the pedagogical parallel to the instructor's daily driver land cleanly.

Flag: the fully autonomous "coding agent" that opens its own pull requests unattended appears to be a paid-plan feature — GitHub's own plans page describes Free's chat/agent access as "limited" without listing a background coding agent under Free.[7] What's confirmed free is in-editor agent mode and the CLI, both genuinely agentic (plan → edit → run → self-correct) even if supervised rather than running unattended in the background. Spot-check this the morning of the workshop.
Live setup time inside the 45-minute slot
~8–12 min, assuming VS Code is pre-installed on the machines beforehand
  1. do this before the sessionPre-install VS Code on lab machines / student laptops from code.visualstudio.com. Thirty simultaneous installer downloads over campus wifi during the workshop will eat the whole 45 minutes — stage it ahead of time.
  2. ~2 minCreate a free GitHub account at github.com/signup — email + password, no card.
  3. ~1 minOpen Extensions (Ctrl+Shift+X) and install GitHub Copilot.
  4. ~1–2 minClick Sign in to GitHub in the Copilot Chat panel; authorize in the browser popup.
  5. ~30 secOpen Copilot Chat (Ctrl+Alt+I) and switch the mode dropdown from Ask to Agent.
  6. ~2 min, optionalFor the closer Claude Code analog, install the standalone Copilot CLI and drive the same loop from a terminal instead of the editor — verify the exact install command live, package naming shifts.
  7. remaining timeHand it a real multi-step task — "add input validation and a test, run the tests, fix any failures" — and let the class watch it plan, edit, run, and self-correct.

Runner-up

More setup, but fully open — and a better live teaching moment for "review the agent before it acts."

Runner-up

Cline (or Kilo Code) + a free Groq API key

Cline is a VS Code extension that is unambiguously agentic — multi-step file edits, terminal and browser tool use, self-correction — and it pauses for a human click before every file write or shell command.[22,23] That approval gate is, by accident, the best live demonstration in this whole list of the "critically review agent output" lesson the workshop is built around. Point it at Groq, whose free tier is gated purely by request rate rather than a spending wallet[42] and which hosts Llama 3.3/4, GPT‑OSS‑120B, Qwen3, and Kimi K2 — all confirmed OpenAI-compatible tool callers.[42,43,44]

Flag: whether Groq's signup itself requires a phone number wasn't stated anywhere in its own docs — do one real signup the day before to confirm. As a backup if Groq gets hammered by 30 simultaneous students, Z.ai's free GLM‑4.7‑Flash scored 95% in an independent tool-calling benchmark and is a strong second BYOK key to have ready.[55,56,59]
  1. ~2–3 minAt console.groq.com, sign up and create an API key under API Keys.
  2. ~1 minIn VS Code Extensions, install Cline (or Kilo Code).
  3. ~2 minIn its settings, set the provider to Groq (or "OpenAI Compatible"), paste the key, and pick llama-3.3-70b-versatile or openai/gpt-oss-120b.
  4. remaining timeGive it a task and approve each proposed edit or command as it runs — the approval queue is the lesson.

An independent 2026 benchmark of 13 small/local models on agentic tool-calling found models under roughly 7B parameters broadly unreliable — low invocation rates, malformed calls, cascading failure across multi-step chains. Standouts at small size: Qwen3.5 4B (97.5%), GLM‑4.7‑Flash and Nemotron Nano 4B (95%). This is the clearest explanation for why "any free API key" is not the same claim as "a free API key that can drive an agent."[59,60]

Classroom risk

What happens when ~30 people sign up from one room, on one wifi network, in a tight window.

  • Google's own account-security system is documented to flag sign-ins from a shared/venue network as suspicious and can force a phone re-verification challenge[61,62] — a real risk if students create fresh Google accounts from the same campus wifi that day. The risk drops a lot if students instead reuse an existing personal Google account.
  • No evidence found of GitHub blocking Philippine phone numbers specifically; blocking is documented for other regions (e.g. +86) but not the Philippines.[9,10] Low risk for this audience.
  • Groq's and OpenRouter's free-tier limits are per-account/per-key by their own docs, not IP-based — simultaneous classroom signups shouldn't trip a shared-IP block the way Google's account layer might.[42,48]
  • No direct evidence either way on university CGNAT triggering abuse detection on any of these providers — flagged as unverified, not ruled out.

What we could not verify live

Flagged explicitly rather than presented as fact.

  • Exact Gemini API free-tier RPM / RPD / TPD — Google's docs defer to a per-account dashboard rather than static published numbers.[40,41]
  • Antigravity CLI's precise quota ceiling — no official quota page found, only community reports of fast exhaustion.[14]
  • Cerebras's reported ~1-week waitlist and 8K-token context cap — a single secondary source, not confirmed against Cerebras's own docs.[46]
  • Mistral's actual current rate limit — conflicting claims (a real monthly allowance vs. an observed 1 RPM ceiling).[51,52,53]
  • GitHub Models' exact numeric limits — the official docs URL returned 404 on this research pass; the numbers above are secondary-source only.[54]
  • Whether Groq, Cerebras, GitHub Models, or Z.ai require a phone number or card at signup — none of the primary docs fetched stated this either way. Do one real signup before the workshop.
  • Whether GitHub Copilot Free's agent access includes the autonomous, background-running coding agent, or only in-editor agent mode — the plans page says "limited chat and agent usage" for Free without listing a coding agent under that tier, while one research pass reported it as included. Treat the conservative reading as what's confirmed.[7]
  • Whether su.edu.ph is recognized instantly in GitHub's institution database — moot right now since Pro signups are paused, but relevant whenever they reopen — not found in any source.
  • OpenAI's hackathon-support credit turnaround — the application page blocked automated fetch; no lead-time figure located anywhere.
